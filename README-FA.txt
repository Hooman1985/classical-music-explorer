# THE CLASSICAL MUSIC EXPLORER — Version 2

نسخه دوم بر پایه طراحی تأییدشده صفحه اصلی ساخته شده و محتوای نسخه اول را حفظ می‌کند.

## اجرا
- برای اجرای محلی، پوشه را با یک وب‌سرور ساده باز کنید؛ به دلیل استفاده از fetch برای فایل‌های JSON، اجرای مستقیم index.html با file:// مناسب نیست.
- برای انتشار، محتویات این پوشه را در شاخه اصلی مخزن GitHub Pages جایگزین کنید.

## امکانات
- صفحه اصلی با طراحی جدید و واکنش‌گرا
- بانک ۳۱ آهنگساز نسخه اول به‌همراه ریچارد کلایدرمن در بخش Beyond Classical
- تصویر محلی آهنگسازان در کارت‌ها و صفحه جزئیات
- فهرست دوره‌ها، خط زمانی، آثار و جست‌وجو
- علاقه‌مندی مستقل برای آهنگسازان و قطعات
- بازی Music Detective و ذخیره امتیاز
- یادداشت‌ها و خروجی پشتیبان My Music World
- PWA و Service Worker برای استفاده آفلاین

## نگهداری
تصاویر در `assets/composers/` قرار دارند و نام فایل‌ها با شناسه آهنگساز در `data/composers.json` هماهنگ است. داده‌ها و علاقه‌مندی‌ها در localStorage همین دستگاه ذخیره می‌شوند.
